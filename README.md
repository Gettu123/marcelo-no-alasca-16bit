# Marcelo no Alasca — versão horizontal 16-bit

Versão adaptada para celular em modo horizontal (16:9), com controles touch, tela cheia e teclado para teste no PC.

## Controles
- ← → / A D: andar
- A / ▲ / Espaço: pular
- B: aceleração/dash
- R: reiniciar fase
- Enter: iniciar/continuar

## GitHub Pages
Mantenha `index.html` na raiz do repositório e publique pela branch `main` / folder `/ (root)`.
